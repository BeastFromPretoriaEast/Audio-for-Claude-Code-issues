# Audio for Claude Code: feedback and issues

**Audio for Claude Code** reads Claude Code's replies aloud in VS Code, with each word highlighted as it's spoken.

- **Install it** from the Visual Studio Marketplace: search for **Audio for Claude Code** in VS Code's Extensions view.
- **Report a problem or suggest an idea:** [open an issue](../../issues/new/choose).

This repository is only for feedback. Audio for Claude Code is free to install and use, but it isn't open source; see the
[licence](LICENSE).
